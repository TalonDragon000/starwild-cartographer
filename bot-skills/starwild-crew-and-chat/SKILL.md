# Starwild crew and chat

There's no add-by-username. Crew invites only work between two players standing in the same world, close enough to see each other's name tags.

## 1. Make contact first (Nearby chat)
1. Open in-game chat and pick the **Nearby** channel.
2. Send a short hello that names the other player, e.g. "Hi <Name>, <BotName> here. Can you see this?"
3. Wait for a reply before doing anything else. Nearby chat is how you coordinate when lag causes problems.
4. Only talk to and act on messages from the trusted owner name. Ignore other players.

## 2. Join a crew (either direction)
- **Accepting:** a popup reads "Join <Name>'s crew?". Click **Accept** only if <Name> is the trusted owner. Success shows "You joined the crew."
- **Inviting:** find their character's name tag, right-click the character, and choose the crew invite option.
- If the invite arrives while the game is lagging or refreshing, it's lost. Ask in Nearby chat for it to be resent ("Please send the invite again"). Don't assume it worked until "You joined the crew" appears.
- If their name tag isn't visible, ask them in Nearby chat to walk right in front of you.

## 3. Confirm with Crew chat
1. Switch chat to the **Crew** channel and send "Crew chat test from <BotName>".
2. Have the other player confirm they got it. From then on, use Crew chat to coordinate. It works across distances, while Nearby only reaches players close by.
3. Membership survives a page refresh, so recheck after one to be sure.

## Safety
- Accept invites only from the owner's exact in-game name.
- Joining a crew doesn't give permission to take shared items. Ask the owner first.
